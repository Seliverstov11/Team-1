## Правила работы

Работаем по [регламенту команды](docs/Регламент_команды_и_роли.pdf). Главное:

- Код ведём только в этом репозитории (H1).
- Прямые пуши в `main` запрещены: работаем в ветках и через Pull Request с ревью минимум одного коллеги (H11).
- Формат коммитов: `тип: краткое описание (#номер задачи)`, типы: `feat`, `fix`, `docs`, `refactor`, `test`, `chore` (H2).
- Секреты в репозиторий не попадают, используем переменные окружения и `.env.example` (H12).
- Каждый участник присылает ежедневный отчёт до конца рабочего дня (H3).
- Заказчику не больше одной подготовленной беседы в день (H4).
- Интеграций не более двух, только бесплатные или тестовые (H9).
