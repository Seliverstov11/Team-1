## Запуск проекта

Backend (API для сайта и CRM):

```bash
cd backend
cp .env.example .env
docker compose up --build      # или cargo run, если установлен Rust
```

API — `http://localhost:8080`, демо-входы сотрудников и подробности — в [`backend/README.md`](backend/README.md).
