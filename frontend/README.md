# Bakeloom — клиентская часть магазина (desktop)

Вёрстка семи страниц магазина товаров для кондитеров по премиальному макету
(Figma «Сладкий мастер — макет сайта» → «🌿 UI-кит · Минималистичный & Премиум», пример главной «вариант 2 · с боковым меню»).
Данные — **заглушки**, backend ещё не подключён.

## Запуск

Нужен Node.js 20+. Из корня репозитория:

```bash
cd frontend && npm start
```

Команда сама ставит зависимости и открывает dev-сервер (http://localhost:5173).

### Доступ из локальной сети

Сервер сразу слушает локальную сеть. При запуске Vite печатает адрес для коллег в строке `Network:`,
например `http://192.168.1.15:5173` — его открывают на другом компьютере в той же сети.

Если с другого компьютера не открывается — порт закрыт файрволом. Открыть (Linux, ufw):

```bash
sudo ufw allow 5173/tcp        # dev-сервер
sudo ufw allow 4173/tcp        # npm run preview, если нужен
```

Закрыть после показа: `sudo ufw delete allow 5173/tcp`. В Windows — разрешить Node.js в брандмауэре
для частных сетей (Windows сам спросит при первом запуске).

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер без установки зависимостей |
| `npm run build` | сборка в `dist/` (Tailwind собирается вместе с проектом, без CDN) |
| `npm run preview` | просмотр собранной версии |

`node_modules/` и `dist/` в репозиторий не попадают (`.gitignore`).

## Стек

- HTML + **Tailwind CSS 4** через сборку (Vite + PostCSS, `@tailwindcss/postcss`)
- **Alpine.js** — весь интерактив
- Шрифты Cormorant Garamond и Montserrat подключены пакетами `@fontsource` (без Google Fonts CDN)
- Без React/Vue и без роутера: каждая страница — отдельный `.html`

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Главная: баннер, категории, популярные товары |
| `catalog.html` | Каталог: сетка, фильтр по категории, поиск, сортировка по цене |
| `product.html?id=<uuid>` | Карточка товара |
| `cart.html` | Корзина: количество, удаление, итого |
| `checkout.html` | Оформление заказа: форма, состав, итог, экран «заказ принят» |
| `favorites.html` | Избранное |
| `contacts.html` | Контакты |
| `tokens.html` | Служебная: все дизайн-токены, кнопки и поля во всех состояниях, проверка сборки |

Фильтры каталога живут в адресе: `catalog.html?category=decor&q=свеч&sort=price-asc`,
поэтому пункты меню и поиск из шапки ведут сразу на нужную выборку.

## Структура

```
index.html, catalog.html, …   страницы
partials/                     общие куски разметки (меню, шапка, подвал, карточка товара)
src/main.js                   Alpine: хранилища и логика страниц
src/api.js                    слой данных — единственное место, где читаются JSON
palette.toml                  цветовая палитра UI-кита — единственный источник цветов
tailwind.config.js            дизайн-токены: читает палитру из palette.toml + шрифты, размеры текста, радиусы, тени
postcss.config.js             подключение Tailwind к сборке
src/input.css                 вход Tailwind: шрифты, компоненты (кнопки, поля, меню)
src/fonts.css                 @font-face для Cormorant Garamond и Montserrat
public/data/*.json            заглушки товаров и категорий
public/img/logo.svg           логотип
```

Общие куски подключаются комментарием `<!-- @include имя.html -->` — его на этапе сборки
заменяет небольшой плагин в `vite.config.js`. Шапку и меню правим в одном месте.

## Дизайн-токены

**Цвета** — только в **`palette.toml`**: у каждого цвета HEX, имя стиля в Figma и назначение.
Шрифты, размеры текста, радиусы и тени — в `tailwind.config.js` (он же читает палитру из `palette.toml`).
Значения перенесены из Figma «🌿 UI-кит · Минималистичный & Премиум» (локальные стили «Премиум/…»).
Посмотреть всё разом: **`/tokens.html`**.

Поменять цвет — исправить `hex` в `palette.toml`. На запущенном `npm run dev` сайт перекрасится сам.

```toml
[brand.dark]                       # → bg-brand-dark, text-brand-dark, border-brand-dark…
hex = "#4A5236"
figma = "Премиум/Primary/Olive"
usage = "Основной цвет: кнопки, меню, баннер"

[error.DEFAULT]                    # DEFAULT → класс без суффикса: text-error
hex = "#B4664A"
```

Правило: в разметке пишем класс по смыслу, а не цвет.

```html
<button class="bg-[#4A5236]">   <!-- нельзя -->
<button class="btn-primary">    <!-- готовый компонент -->
<p class="text-error">          <!-- токен по смыслу -->
```

| Группа | Классы |
|---|---|
| Фирменные | `brand-dark`, `brand-dark-hover`, `brand-light`, `brand-gold`, `brand-gold-hover`, `brand-gold-light`, `brand-gold-soft`, … |
| Поверхности и текст | `surface`, `surface-sand`, `ink`, `ink-muted`, `ink-placeholder`, `on-dark`, `on-dark-muted` |
| Линии и состояния | `line`, `line-strong`, `success`, `success-soft`, `error`, `error-soft`, `disabled` |
| Шрифты | `font-heading` (Cormorant Garamond), `font-body` (Montserrat) |
| Текст | `text-display`, `text-h1`…`text-h3`, `text-price`, `text-lead`, `text-body`, `text-small`, `text-button`, `text-overline` |
| Радиусы и тени | `rounded-control` / `search` / `card` / `panel` / `check`, `shadow-subtle`, `shadow-lift` |
| Компоненты | `btn-primary`, `btn-gold`, `btn-outline`, `btn-link` (+ `btn-l`, `btn-s`), `field`, `chip`, `counter`, `eyebrow`, `demo-tag` |

Исключение — SVG-иллюстрации-заглушки товаров (`partials/product-image.html`): это картинки, а не интерфейс;
уйдут, когда появятся фото (`image_url`).

## Данные и подключение API

Товары и категории лежат в `public/data/products.json` и `public/data/categories.json`,
в разметке товаров нет. Поля — как в контракте API:

```json
{ "id": "uuid", "category_id": "uuid", "name": "…", "sku": "…", "price": "1880.00",
  "unit": "шт", "available_qty": "24", "image_url": null }
```

Чтобы перейти на backend, достаточно поправить `src/api.js` (места помечены `TODO(API)`):
адрес API, пути `/products`, `/categories` и `createOrder()` — сейчас он ничего не отправляет
и возвращает номер-заглушку `DEMO-XXXXXX`. Разметку трогать не нужно.

Чего нет в контракте и как это показано:

- **описание товара** — на карточке блок «Описание» с пометкой «Заглушка»;
- **фасовка** — берётся из хвоста названия (`…, 1 кг`), иначе показывается единица продажи;
- **популярность** — данных о продажах нет, на главной показаны первые товары в наличии с подписью «Демо-подборка»;
- **категории** — `slug` используется в адресе каталога (`?category=decor`).

Корзина и избранное хранятся в `localStorage` (`bakeloom.cart`, `bakeloom.favorites`):
переживают переход между страницами и перезагрузку, счётчики в шапке общие.

## Переходы между страницами без мерцания

- Стили подключены `<link>` в `<head>` — страница не рисуется без CSS.
- Скрипт с `blocking="render"`: первый кадр рисуется уже после Alpine, без «пустых» состояний и `0 ₸` в шапке.
- Справочник товаров кэшируется в `sessionStorage` (`bakeloom.data`): на следующей странице данные есть сразу,
  свежие подгружаются в фоне. Скелетон показывается только при самом первом заходе.
- Шрифты — свои `@font-face` (`src/fonts.css`) с `font-display: block`: текст не перескакивает с системного шрифта на фирменный.
- `@view-transition` (Chrome, Edge, Safari 18): страницы сменяются плавно, меню и шапка стоят на месте, анимируется только контент.
  В браузерах без поддержки — обычный переход. Уважается `prefers-reduced-motion`.
- Активный раздел подсвечивается чистым CSS по `<body data-page="…">`, поэтому виден с первого кадра;
  в каталоге и на карточке товара дополнительно подсвечивается категория. Раскрытие меню каталога запоминается на сессию.

## Что сознательно не показано

По условиям задачи на странице нет того, что заказчик не подтверждал: бесплатной доставки
от суммы, скидок, промокодов, сроков доставки, способов оплаты. Пункты меню из макета
«Новинки», «Скидки», «Мастер-классы», «Доставка», блок «Персональный подбор», кабинет
и полоса преимуществ убраны. Способы получения в заказе — «Самовывоз» и «Доставка»
без условий («условия сообщит менеджер»).

Цены — в тенге (₸). Демо-контент подписан: полоса «Демо» вверху каждой страницы, метка
«Демо» на каждом товаре, артикулы `DEMO-…`, «Демо-контакты» в меню и подвале.

## Ограничения

- Только desktop. Проверено без горизонтального скролла на 1280, 1440 и 1920 px.
  Мобильная адаптация — отдельная задача; ширины по возможности заданы в `rem`,
  долях и `minmax()`, а не жёсткими пикселями.
- Логотип — вариант 1 Bakeloom для тёмного фона (`public/img/logo.svg`).
