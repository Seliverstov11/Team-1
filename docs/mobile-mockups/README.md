# Мобильные макеты Bakeloom

Статичный HTML, открывается двойным кликом (шрифты подгружаются из Google Fonts).

- `index.html` — обзор всех экранов, переключатель «по одному экрану», ширины 375 и 360 px.
- `screens/NN.html` — каждый экран отдельным файлом.

Решения заказчика, учтённые в макетах: бургера нет; нижняя навигация Главная · Каталог · Избранное · Профиль; корзина только в шапке; на оформлении обязательны имя, телефон, адрес; промокодов, бесплатной доставки и онлайн-оплаты нет.

Заглушки в макетах подписаны на экране: минимум и шаг для весового товара, способ входа, телефон и адрес самовывоза, список статусов заказа.
